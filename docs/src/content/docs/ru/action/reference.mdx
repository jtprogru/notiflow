## Замечания по отдельным входам

### `status`

Обязателен, без дефолта. Манифест composite action вычисляет выражения `${{ }}` при
загрузке, до появления контекста job, поэтому `default: ${{ job.status }}` уронил бы весь
workflow с `Unrecognized named-value: 'job'`. Передавай из вызывающего кода:
`${{ job.status }}` внутри job, `${{ needs.<job>.result }}` из другого.

### `chat_id`

Один чат. Целое (отрицательное для групп и супергрупп) либо `@channelusername` из 4–32
словных символов. Запятая отклоняется с кодом 11, см.
[гайд по миграции](/notiflow/ru/action/migration/).

### `parse_mode`

`MarkdownV2` (по умолчанию), `HTML` или `none`. `Markdown` принимается как алиас
`MarkdownV2` и печатает предупреждение: notiflow экранирует значения по правилам V2, и
отдавать такое легаси-парсеру Telegram — значит получить битое или отклонённое сообщение.

### `disable_web_page_preview`

Имя входа не изменилось с v1, но на проводе теперь
`link_preview_options.is_disabled` — плоское поле Telegram задепрекейтил.

### `edit_message_id`

Превращает вызов в `editMessageText`. `disable_notification` и `message_thread_id` при
редактировании отбрасываются: Telegram их там не принимает, и передача превратила бы
рабочую конфигурацию в 400.

### `fail_on_error`

По умолчанию `false`. Неудачное уведомление не затирает результат, который реально дал job;
ставь `true`, когда доставка — часть контракта.

## Переменные окружения

Обвязка отображает каждый вход в переменную `NF_*` и передаёт бинарю. Ещё две читаются
напрямую, и обе ограничены внутри workflow:

| Переменная | Смысл |
|---|---|
| `NF_API_BASE` | Базовый URL Bot API. Внутри Actions учитываются только `https://api.telegram.org` и loopback — всё остальное игнорируется с предупреждением, чтобы переменная, выставленная предыдущим шагом того же job, не увела токен. |
| `NF_BIN` | Путь к бинарю; нужен, чтобы гонять обвязку против локальной сборки. |

В CLI `--api-base` принимает любой `http(s)` URL: self-hosted Bot API — легитимный
сценарий, и там значение выбирает сам пользователь.
