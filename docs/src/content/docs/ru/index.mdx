## Тридцать секунд в workflow

```yaml
- uses: jtprogru/notiflow@v2
  if: always()
  with:
    bot_token: ${{ secrets.TELEGRAM_BOT_TOKEN }}
    chat_id: ${{ secrets.TELEGRAM_CHAT_ID }}
    status: ${{ job.status }}
```

## Тридцать секунд в терминале

```bash
brew install jtprogru/tap/notiflow
export NOTIFLOW_BOT_TOKEN=123456:AA...
notiflow send --chat-id -1001234567890 --message "деплой закончился"
./long-build.sh | notiflow send -c -1001234567890 --stdin
```

Переезжаешь с v1? Входы не изменились, кроме одного удаления — см.
