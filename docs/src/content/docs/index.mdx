## Thirty seconds in a workflow

```yaml
- uses: jtprogru/notiflow@v2
  if: always()
  with:
    bot_token: ${{ secrets.TELEGRAM_BOT_TOKEN }}
    chat_id: ${{ secrets.TELEGRAM_CHAT_ID }}
    status: ${{ job.status }}
```

## Thirty seconds in a terminal

```bash
brew install jtprogru/tap/notiflow
export NOTIFLOW_BOT_TOKEN=123456:AA...
notiflow send --chat-id -1001234567890 --message "deploy finished"
./long-build.sh | notiflow send -c -1001234567890 --stdin
```

Upgrading from v1? The inputs are unchanged except for one removal — see the
[migration guide](/notiflow/action/migration/).
